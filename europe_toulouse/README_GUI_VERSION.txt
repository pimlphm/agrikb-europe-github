AgriKB Europe Toulouse GUI
==========================

This package is based on the original AgriKB TrustedPC OneClick project.

Version changes:
- English GUI.
- Default object: Toulouse, Occitanie, France.
- Default market: Toulouse MIN Occitanie wholesale market.
- Default port: 8020.
- Backend, knowledge base, runtime and one-click launch mechanism are preserved.

Start:
1. Double click START_AgriKB_EUROPE_TOULOUSE_GUI.bat
2. The browser opens http://127.0.0.1:8020/ui/

Original start scripts are retained for compatibility.
