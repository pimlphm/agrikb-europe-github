# Original Data

This folder contains original source materials for the AeroKB project.

## Contents

```text
知识产权/
  patent application drafts
  software copyright documents
  generated DOCX versions
  patent figures
  editable figure exports
  English publication materials
  document-generation and patent-rewrite scripts
```

## How This Relates To The Runnable App

The runnable app lives in the project root. These original materials are the upstream project assets used to describe, patent, demonstrate and document the system.

The app can ingest documents from this folder, but this folder is not required for the backend to start.

## Publication Policy

Treat these files as private by default. They may include patent claims, implementation details and project-specific technical descriptions.

For public GitHub publication, use a redacted sample dataset instead of the full `知识产权` folder unless publication has been approved.
