说明

自 2009 年起，加拿大农业及农业食品部 (AAFC) 科学技术处 (STB) 的地球观测团队开始生成年度作物类型数字地图。该研究重点关注 2009 年和 2010 年的草原省份，采用基于决策树 (DT) 的方法，使用基于光学（Landsat-5、AWiFS、DMC）和雷达（Radarsat-2）的卫星图像。自 2011 年种植季开始，这项活动已扩展到其他省份，以支持全国农作物库存。迄今为止，这种方法能够始终如一地提供作物清单，在 30 米的最终空间分辨率下（2009 年和 2010 年为 56 米），达到至少 85% 的总体目标准确率。

通过 Earth Engine 探索

重要提示：Earth Engine 是一个平台，可用于对地理空间数据集进行 PB 级科学分析和可视化，既可用于公益用途，也可供企业和政府用户使用。Earth Engine 可免费用于研究、教育和公益用途。如需开始使用，请注册以获取 Earth Engine 访问权限。

代码编辑器 (JavaScript)

var dataset = ee.ImageCollection('AAFC/ACI');
var crop2016 = dataset
    .filter(ee.Filter.date('2016-01-01', '2016-12-31'))
    .first();
Map.setCenter(-103.8881, 53.0372, 10);
Map.addLayer(crop2016, {}, '2016 Canada AAFC Annual Crop Inventory');

Python 设置

如需了解 Python API 和如何使用 geemap 进行交互式开发，请访问 Python 环境页面。

import ee
import geemap.core as geemap
