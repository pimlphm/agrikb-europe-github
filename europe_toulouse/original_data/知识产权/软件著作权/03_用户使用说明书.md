# 基于工业本体的民机适航知识图谱智能分析系统

# 用户使用说明书

**版本：V4.0**

**编制日期：2026年04月**

---

## 1. 软件概述

### 1.1 软件名称

基于工业本体的民机适航知识图谱智能分析系统（简称：民机适航知识图谱系统）

### 1.2 用途

本软件面向民用航空器适航认证领域的工程师和研究人员，提供以下核心能力：

- 从技术文档中自动提取知识实体和关系，构建本体知识图谱
- 执行ARP4761标准安全评估（FHA/PSSA/SSA/CCA/DAL分配）
- DO-178C追溯完整性检查（需求→设计→代码→测试）
- 变更影响多维度分析
- 中/美/欧三方适航标准即时查阅和交叉引用
- 按机型积累和管理工程经验

### 1.3 适用对象

- 空客/波音等民机设计团队
- 适航认证工程师
- 系统安全评估工程师
- MBSE架构师
- 航空航天科研机构研究人员

## 2. 安装指南

### 2.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 64位 | Windows 11 64位 |
| 处理器 | Intel i5 / AMD Ryzen 5 | Intel i7 / AMD Ryzen 7 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 2 GB 可用空间 | 10 GB SSD |
| 显卡 | 支持CUDA的NVIDIA GPU（可选） | NVIDIA RTX 3060以上 |
| 特殊硬件 | — | 华为昇腾910B NPU（国产化部署） |

### 2.2 安装步骤

#### 步骤一：安装Python环境

确保系统已安装Python 3.10或以上版本。

#### 步骤二：安装Ollama

访问Ollama官网(ollama.ai)下载并安装。安装完成后下载推荐模型：

```bash
ollama pull qwen2.5:7b-instruct
```

#### 步骤三：安装依赖

双击`install.bat`或手动执行：

```bash
pip install -r requirements.txt
```

#### 步骤四：启动系统

双击`启动.bat`或手动执行：

```bash
python main.py
```

### 2.3 配置说明

编辑`config.yaml`文件可修改以下配置：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `backend` | `ollama` | 推理后端：`ollama`或`vllm_ascend` |
| `ollama.base_url` | `http://localhost:11434` | Ollama服务地址 |
| `ollama.model` | `qwen2.5:7b-instruct` | 默认模型 |
| `ollama.temperature` | 0.3 | 推理温度 |
| `ollama.max_tokens` | 4096 | 最大输出长度 |

## 3. 操作指南

### 3.1 主界面布局

启动后进入暗色航空主题界面，顶部为菜单栏和工具栏，中央为七个标签页：

```
┌─────────────────────────────────────────────┐
│ 菜单栏: 文件 | 适航认证 | 知识分析 | 经验管理   │
│        | 标准库 | 归档管理 | 帮助             │
├─────────────────────────────────────────────┤
│ 工具栏: [后端标识] [模型下拉选择 ▼] [刷新模型]  │
├─────────────────────────────────────────────┤
│ ┌─────┬──────┬──────┬──────┬──────┬────┬────┐│
│ │对话 │图谱  │追溯  │安全  │经验  │标准│文档││
│ │交互 │可视化│矩阵  │评估  │管理  │库  │管理││
│ └─────┴──────┴──────┴──────┴──────┴────┴────┘│
│                                              │
│              [当前标签页内容]                   │
│                                              │
├─────────────────────────────────────────────┤
│ 状态栏: 后端状态 | 模型名称 | 图谱节点/边数     │
└─────────────────────────────────────────────┘
```

### 3.2 导入文档分析

1. 点击菜单**文件 → 导入文档**或使用快捷键
2. 在文件选择对话框中选择要分析的文档（支持PDF/DOCX/MD等14种格式）
3. 系统自动调用大语言模型进行知识提取
4. 提取完成后，知识图谱标签页自动更新
5. 经验管理标签页同步显示新提炼的经验

也可批量扫描：点击**文件 → 扫描文件夹**，选择包含文档的文件夹。

### 3.3 知识图谱浏览

在**知识图谱**标签页中：

- **交互式图谱**：使用鼠标滚轮缩放，拖拽移动画布，点击节点查看详情
- **节点颜色**：按实体类型着色
- **边颜色**：按赤橙黄绿青蓝紫七级色谱表示关联强度
- **实体树**：左侧树形结构浏览所有实体和关系
- **导出**：可导出HTML交互式图谱

### 3.4 安全评估

通过菜单**适航认证**或**安全评估**标签页：

1. **安全评估 FHA/DAL分配**：对当前知识图谱执行功能危险评估，自动生成危险列表和DAL等级分配建议
2. **DO-178C追溯完整性检查**：检查需求→设计→代码→测试的完整追溯链，发现断链和孤立需求
3. **变更影响分析**：输入变更项，系统自动评估上游、下游、横向、安全、认证五个维度的影响
4. **生成追溯矩阵报告**：输出结构化追溯矩阵

### 3.5 标准库查阅

在**标准库**标签页中：

- **搜索框**：输入标准编号（如"DO-178C"）或关键词（如"安全评估"）
- **当局过滤**：下拉选择FAA/EASA/CAAC或全部
- **类别过滤**：按软件适航、安全评估、适航规章等分类
- **标准详情**：点击标准后右侧显示完整信息（范围、条款、交叉引用）
- **交叉引用**：查看三方等效标准对照关系

### 3.6 经验管理

在**经验管理**标签页中：

- **设置当前型号**：指定当前分析的机型项目（如B787、A320neo）
- **浏览经验**：按永久/临时分类，支持按机型过滤
- **审核经验**：选中经验后可审核通过或驳回
- **提升经验**：将临时经验提升为永久经验
- **生成审计报告**：生成跨型号经验汇总的中英文报告
- **打开经验文件夹**：直接访问.md格式的经验文件进行人工编辑

### 3.7 模型切换

工具栏提供运行时模型切换功能：

1. 点击**刷新模型列表**按钮获取当前可用模型
2. 在下拉框中选择目标模型
3. 模型即时切换，无需重启系统

### 3.8 演示案例

系统内置10个演示文档，涵盖：

- **波音**：B787环境控制系统安全评估、B787电气系统需求、B787数字线程框架、B777X飞控MBSE模型、B777X复合材料翼结构
- **空客**：A320neo发动机控制软件、A320neo电传飞控认证、A350 EWIS认证、A350飞控系统设计、A350 MBSE知识工程

点击菜单**文件 → 分析演示文档**可一键加载全部演示。

## 4. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 启动提示"Ollama未连接" | 确认已运行`ollama serve`命令 |
| 模型列表为空 | 先通过`ollama pull`下载至少一个模型 |
| 分析速度慢 | 使用GPU加速或切换更小的模型 |
| 图谱显示空白 | 确认已导入至少一个文档 |
| 中文显示乱码 | 确保系统默认编码为UTF-8 |
