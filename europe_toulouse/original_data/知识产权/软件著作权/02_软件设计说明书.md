## 1. 引言

### 1.1 编写目的

本文档详细描述"基于工业本体的民机适航知识图谱智能分析系统"的软件架构设计、模块划分、数据结构、接口规范等技术内容，为软件著作权登记提供技术说明依据。

### 1.2 项目背景

民用航空器适航认证涉及海量标准、需求、设计和验证文档，其中的知识关联错综复杂。传统的人工管理方式难以全面追溯需求-设计-代码-测试之间的映射关系，容易遗漏安全性评估项目。本系统基于工业本体（IOF/BFO）框架与大语言模型（LLM）技术，构建面向民机适航领域的智能知识图谱，自动化完成知识提取、安全评估、追溯分析和经验积累，为空客、波音等民机设计团队提供适航认证工作流集成工具。

### 1.3 定义与缩写

| 缩写 | 全称 | 说明 |
|------|------|------|
| IOF | Industrial Ontologies Foundry | 工业本体基础 |
| BFO | Basic Formal Ontology | 基本形式本体 |
| LLM | Large Language Model | 大语言模型 |
| DAL | Development Assurance Level | 研制保证等级 |
| FHA | Functional Hazard Assessment | 功能危险评估 |
| PSSA | Preliminary System Safety Assessment | 初步系统安全评估 |
| SSA | System Safety Assessment | 系统安全评估 |
| CCA | Common Cause Analysis | 共因分析 |
| MBSE | Model-Based Systems Engineering | 基于模型的系统工程 |
| IMA | Integrated Modular Avionics | 综合模块化航电 |
| NPU | Neural Processing Unit | 神经网络处理单元 |

## 2. 系统总体架构

### 2.1 分层架构

本系统采用四层架构设计：

```
┌─────────────────────────────────────────────────┐
│           表示层 (Presentation Layer)              │
│    PyQt5 GUI · 暗色航空主题 · 7标签页 · 图谱可视化   │
├─────────────────────────────────────────────────┤
│           业务层 (Business Logic Layer)             │
│  AgentEngine · 6角色 · 适航工作流 · 标准库查询       │
├─────────────────────────────────────────────────┤
│           知识层 (Knowledge Layer)                  │
│  OntologyEngine · ExperienceEngine · StandardsLib  │
│  RDF三元组 · NetworkX图 · 74类型 · 36关系 · 7色谱    │
├─────────────────────────────────────────────────┤
│           基础层 (Infrastructure Layer)             │
│  LLMClient (Ollama/vLLM-Ascend) · DocParser · IO   │
└─────────────────────────────────────────────────┘
```

### 2.2 核心文件结构

```
知识库/
├── main.py                         # 应用入口：初始化各引擎并启动GUI
├── config.yaml                     # 全局配置：后端、模型、路径
├── requirements.txt                # Python依赖清单
├── core/                           # 核心引擎层
│   ├── ontology_engine.py          # 本体知识图谱引擎 (1200+ 行)
│   ├── llm_agent.py                # LLM多角色Agent引擎 (830+ 行)
│   ├── experience_engine.py        # 经验积累与审计引擎 (600+ 行)
│   ├── standards_library.py        # 适航标准库引擎 (550+ 行)
│   ├── graph_visualizer.py         # 图谱可视化生成器
│   ├── doc_parser.py               # 多格式文档解析器
│   └── archiver.py                 # 文档监控与归档
├── gui/
│   └── main_window.py              # PyQt5主界面 (2100+ 行)
├── standards/                      # 适航标准库 (中/美/欧)

```

### 2.3 初始化流程

```
main.py
  → 加载config.yaml配置
  → 创建QApplication, 显示Splash启动屏
  → create_llm_client() 初始化LLM后端(Ollama或vLLM-Ascend)
  → OntologyEngine() 加载/创建知识图谱
  → ExperienceEngine() 加载历史经验索引
  → StandardsLibrary() 初始化标准库并生成文件
  → AgentEngine(llm, ontology, experience, standards) 组装Agent
  → MainWindow(agent, ontology, config, experience, standards) 启动GUI
```

## 3. 模块详细设计

### 3.1 本体知识图谱引擎 (ontology_engine.py)

#### 3.1.1 三层本体架构

| 层级 | 命名空间 | 实体数 | 说明 |
|------|----------|--------|------|
| BFO顶层 | `http://purl.obolibrary.org/obo/BFO_` | 6 | entity, process, function, quality, role, disposition |
| IOF核心层 | `https://spec.industrialontologies.org/ontology/core/Core/` | 18 | requirement, design, verification, interface, constraint等 |
| 航空领域层 | `http://aviation-kb.org/ontology#` | 50 | aircraft_req, fha_item, logical_architecture等 |

#### 3.1.2 关联强度色谱

| 色谱 | 强度区间 | RGB值 | 语义 |
|------|----------|-------|------|
| 赤 | 0.86-1.00 | #FF0000 | 必要依赖/直接因果 |
| 橙 | 0.72-0.85 | #FF6600 | 强关联/约束传递 |
| 黄 | 0.58-0.71 | #FFCC00 | 中强关联 |
| 绿 | 0.44-0.57 | #33CC33 | 中等关联 |
| 青 | 0.30-0.43 | #00CCCC | 弱关联/参考 |
| 蓝 | 0.16-0.29 | #3366FF | 间接关联 |
| 紫 | 0.00-0.15 | #9933FF | 潜在关联/推测 |

#### 3.1.3 核心类：OntologyEngine

**主要方法：**

| 方法 | 功能 |
|------|------|
| `add_entity(label, entity_type, properties)` | 添加实体节点，自动推断类型层级 |
| `add_relation(source, target, relation_type, strength)` | 添加带强度的关系边 |
| `get_statistics()` | 返回图谱统计（节点数、边数、平均强度） |
| `find_missing_links()` | 基于图结构预测缺失的知识链接 |
| `find_clusters()` | 社区发现算法聚类知识簇 |
| `find_bridge_nodes()` | 介数中心性发现关键桥接节点 |
| `suggest_next_generation()` | 知识演进推理，建议扩展方向 |
| `save() / load()` | JSON持久化与加载 |

### 3.2 LLM多角色Agent引擎 (llm_agent.py)

#### 3.2.1 双后端架构

```
                ┌──────────────┐
                │  AgentEngine │
                │  (6个角色)   │
                └──────┬───────┘
                       │
            ┌──────────┴──────────┐
            │                     │
    ┌───────┴───────┐     ┌──────┴───────┐
    │ OllamaClient  │     │ VLLMAscend   │
    │ localhost:11434│     │ Client       │
    │ REST API       │     │ OpenAI兼容API│
    └───────────────┘     │ Docker容器   │
                          │ 昇腾910B NPU │
                          └──────────────┘
```

#### 3.2.2 六大Agent角色

| 角色 | 系统提示关键词 | 职责 |
|------|--------------|------|
| universal_extractor | IOF/BFO实体提取 | 从文档提取结构化知识，输出实体和关系JSON |
| ontology_reasoner | V模型/安全链/DAL | 基于图谱深度推理，发现风险和改进建议 |
| document_organizer | 民机文档分类 | 按ATA章节、文档类型自动分类归档 |
| safety_assessor | ARP4761 FHA/PSSA/SSA | 执行安全评估，输出危险列表和DAL分配 |
| v_model_tracer | DO-178C追溯 | 检查HLR/LLR/代码/测试追溯完整性 |
| impact_analyzer | 五维变更影响 | 评估变更的上下游/横向/安全/认证影响 |

#### 3.2.3 核心流程：文档分析

```
analyze_document(doc_content, doc_name, aircraft_program)
  → 构建LLM提示词（含IOF/BFO类型体系引导）
  → 注入历史经验上下文 (experience.get_experience_context)
  → 注入相关标准条款上下文 (standards.get_context_for_prompt)
  → 调用LLM推理 (universal_extractor角色)
  → 解析JSON响应，提取entities和relations
  → 写入OntologyEngine知识图谱
  → 自动提炼新经验 (experience.extract_from_analysis)
  → 返回结构化分析结果
```

### 3.3 经验积累与审计引擎 (experience_engine.py)

#### 3.3.1 经验数据模型

```
ExperienceEntry:
  ├── id: UUID唯一标识
  ├── title_zh / title_en: 中英文标题
  ├── category: 分类 (design_pattern/safety_lesson/traceability_rule/...)
  ├── content_zh / content_en: 中英文内容
  ├── level: permanent(永久) / temporary(临时)
  ├── applicable_standards: 关联标准列表
  ├── applicable_systems: 适用系统列表
  ├── confidence: 置信度 0-1
  ├── rationale_zh / rationale_en: 依据
  ├── conditions_zh / conditions_en: 适用条件
  ├── source: 来源文档
  ├── aircraft_program: 所属机型项目
  ├── review_status: pending/approved/rejected
  ├── usage_count: 被引用次数
  └── created_at / updated_at: 时间戳
```

#### 3.3.2 经验闭环流程

```
文档分析 → LLM提炼经验 → 写入JSON索引 + 生成.md文件
                                    ↓
             ┌─────────────────────┴─────────────────────┐
             │                                           │
  permanent_zh.md / permanent_en.md      temporary_zh.md / temporary_en.md
             │                                           │
             └─────── 人工审核 → 提升/驳回 ──────────────┘
                          ↓
             下次分析自动加载经验上下文
```

### 3.4 适航标准库 (standards_library.py)

#### 3.4.1 标准体系覆盖

| 当局 | 标准数 | 覆盖领域 |
|------|--------|----------|
| FAA (美国) | 9 | 适航规章、软件/硬件适航、系统研制、安全评估、环境试验、航电、信息安全 |
| EASA (欧洲) | 8 | 与FAA等效的ED系列标准 |
| CAAC (中国) | 6 | CCAR、CTSO、咨询通告系列 |

#### 3.4.2 标准注入机制

Agent分析文档时，根据文档关键词自动检索相关标准，将标准条款摘要注入LLM提示词，确保分析结果符合适航标准要求。

### 3.5 文档解析器 (doc_parser.py)

支持14种文档格式统一解析：

| 格式 | 解析库 | 说明 |
|------|--------|------|
| PDF | PyPDF2 + pdfplumber | 文本提取，表格保留 |
| DOCX | python-docx | 段落、表格、样式 |
| XLSX | openpyxl | 工作表、单元格 |
| PPTX | python-pptx | 幻灯片文本 |
| MD/TXT/RST/TEX | 原生解析 | 编码自动检测 |
| HTML/XML | BeautifulSoup + lxml | 标签清理 |
| JSON/YAML/CSV | 标准库 | 结构化数据 |
| ReqIF | XML解析 | 需求交换格式 |

### 3.6 图谱可视化 (graph_visualizer.py)

基于vis-network.js库生成交互式HTML知识图谱：
- 节点：按实体类型着色和图标标注
- 边：按七级色谱渲染关联强度
- 布局：力导向/层级双模式
- 交互：缩放、拖拽、节点详情弹窗、强度图例

### 3.7 GUI主界面 (main_window.py)

七大功能标签页：

| 标签页 | 功能 |
|--------|------|
| 对话交互 | 上下文感知的LLM对话，快捷命令按钮 |
| 知识图谱 | 交互式图谱浏览，实体/关系树 |
| 追溯矩阵 | 需求-设计-代码-测试追溯关系矩阵 |
| 安全评估 | FHA/DAL分配、DO-178C追溯检查结果展示 |
| 经验管理 | 按机型浏览/审核/提升经验，统计汇总 |
| 标准库 | 搜索/过滤/浏览中美欧三方适航标准 |
| 文档管理 | 文件导入、扫描目录、自动归档 |

## 5. 接口设计

### 5.1 LLM后端接口

| 接口 | 协议 | 说明 |
|------|------|------|
| Ollama Chat | HTTP REST `/api/chat` | 本地Ollama推理 |
| Ollama Tags | HTTP REST `/api/tags` | 获取可用模型列表 |
| vLLM-Ascend | HTTP REST `/v1/chat/completions` | OpenAI兼容API |

### 5.2 内部模块接口

| 调用方 | 被调用方 | 接口 | 数据流 |
|--------|----------|------|--------|
| AgentEngine | LLMClient | `chat(messages, system)` | 提示词→LLM响应 |
| AgentEngine | OntologyEngine | `add_entity() / add_relation()` | 分析结果→图谱 |
| AgentEngine | ExperienceEngine | `get_experience_context()` | 历史经验→提示词 |
| AgentEngine | ExperienceEngine | `extract_from_analysis()` | 分析结果→新经验 |
| AgentEngine | StandardsLibrary | `get_context_for_prompt()` | 标准条款→提示词 |
| MainWindow | AgentEngine | `analyze_document()` | 文档→分析结果 |
| MainWindow | OntologyEngine | `get_statistics()` | 图谱统计→界面 |

## 6. 安全性设计

1. **全离线运行**：系统无需互联网，满足军工保密环境
2. **本地推理**：LLM模型部署在本机或局域网内，数据不外传
3. **文件级存储**：JSON/RDF文件存储，无需外部数据库服务
4. **可审计性**：所有经验以.md文件存在，支持人工审核
5. **国产化**：支持华为昇腾NPU，避免对境外AI芯片依赖
