说明

此图片集提供了对底层区域被商品占据的概率的像素级估计。 概率估计以 10 米为单位进行划分，并且由机器学习模型生成。如需了解详情，请参阅 GitHub 上 Forest Data Partnership 代码库 中的技术文档。

此图片集的主要目的是支持 Forest Data Partnership的使命，即通过 协作改进全球监测、供应链跟踪和 恢复工作，阻止和扭转因商品生产而造成的森林损失。

此数据集目前涵盖泛热带地区（纬度 -24 至 24 度）。

随着社区提供更多数据，以及用于生成地图的模型不断改进，此社区数据产品会不断发展。如果您想提供一般反馈或 提供更多数据集来改进这些图层，请通过 此表单与我们联系。

如需了解此数据集的技术文档和限制，请参阅此 GitHub README 。

2025b 版本与 2025a 版本的区别在于，2025b 版本基于 AlphaEarth Foundations 卫星嵌入，因此与 2025a 相比，地理和时间覆盖范围更广。此外，2025b 还包含其他输入数据和经过改进的输入数据处理流水线。请注意，在某些情况下，2025a 模型可能表现更好。

代码编辑器 (JavaScript)

Map.setCenter(-88.84, 14.57, 12);

var collection = ee.ImageCollection(
    'projects/forestdatapartnership/assets/coffee/model_2025b');

var coffee2020 = collection.filterDate('2020-01-01', '2020-12-31').mosaic().gt(0.28);
Map.addLayer(
  coffee2020.selfMask(), {min: 0.5, max: 1, palette: 'white,brown'}, 'coffee 2020');

var coffee2024 =
    collection.filterDate('2024-01-01', '2024-12-31').mosaic().gt(0.28);
Map.addLayer(
    coffee2024.selfMask(), {min: 0.5, max: 1, palette: 'white,green'},
    'coffee 2024');
